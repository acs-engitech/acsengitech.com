SIMATIC S7-400 Series

Siemens S7-400 PLC

The SIMATIC S7-400 is the most powerful Automation System within SIMATIC — a high-performance process controller with superb communication capability and integrated interfaces.

Ideal for the coordination of entire systems, the graded range of CPUs enables scalable performance. Process controller signal modules can be inserted and removed while the system is live (hot swapping).

Hot Swapping Capability
Signal modules can be inserted and removed while the system is live — making it very easy to expand the system or replace modules without production stops.
Module Range
  • Compact CPUs
  • Stan alone CPUs
  • Digital Input / Output Modules
  • Analog Input / Output Modules
  • Communication Modules
  • Special Function Modules
